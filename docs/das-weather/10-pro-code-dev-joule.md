# Get Started Developing Joule Assistants in SAP BTP (Pro-Code)

This mission provides a step-by-step guide to developing Joule capabilities and assistants using the released "Joule Studio CLI" 1.5.21 and/or the "Joule Studio code editor" VS Code Extension, as pro-code development tools. 

>Note: This mission focuses on the released Joule Application on SAP BTP and the related pro-code development tools for it.  

It is not about the new Joule Studio, which has been announced at [Sapphire 2026](https://news.sap.com/2026/05/new-joule-studio-enterprise-scale-agentic-development/).




### About this Mission

This mission describes how to:

- Subscribe to Joule in SAP BTP
- Optional: Set up Build Work Zone and build a formation with Joule 
- Set up Joule Studio CLI
- Set up Joule Studio Code Editor, a VS Code extension
- Create a simple Joule capability ("how is the weather?")
- Compile an assistant 
- Deploy an assistant in your tenant in SAP Business Technology Platform (BTP)



### Prerequisites before continuing the mission

- You must have an SAP BTP **Enterprise Account**. Joule is not available in the BTP Trial.
- You must have an entitlement for Joule.
- Optional: You have an entitlement for SAP Build Work Zone. Not required for development only.

Prerequisites (later in the mission):
- You must have created a service instance of Joule.
- You must be assigned to the `extensibility_developer` and `end_user` role in SAP BTP.


#### Pro-Code Development Tools for Joule

The pro-code development tools for Joule provide a complete environment for building, validating, and managing assistants. They consist of two tools:

- **Joule Studio CLI** — command-line tool for terminal-based and CI/CD workflows
- **Joule Studio Code Editor** — VS Code extension for a guided, visual development experience
